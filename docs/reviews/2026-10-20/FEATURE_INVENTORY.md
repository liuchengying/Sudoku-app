复盘日期：2026-10-20。方式：只读清点当前源码，对照 [当前工程概览](../../PROJECT_OVERVIEW.md)、[2026-09-30 原始评估](../2026-09-30/ASSESSMENT.md) 与交付任务历史。本次为普通咨询，未创建交付任务，未修改业务代码，未启动应用或设备。

## 1. 结论

核心玩法闭环已经完整：主菜单 → 选关（闯关/练习）→ 对局（填数/笔记/撤销/检查/提示/书签）→ 结算（奖牌/积分）→ 历史/回放 → 统计/成就，加上每日挑战、自定义导入、教程、设置和首次引导，四个游戏模式（CAMPAIGN/PRACTICE/DAILY/CUSTOM）全部可用。2026-09-30 评估提出的四轮建议（可靠性、题目体系、教学效率、长期目标）除"变体数独"外均已落地，全仓无 TODO/FIXME 标记，15 个设置项全部有实际消费点。

当前主要缺口不在"缺功能"，而在三件事：一是从未做真机/正式构建验收（布局、触摸、音效、震动、折叠屏姿态均未经设备验证）；二是解题引擎技巧上限（教程已写 Swordfish、XY-Wing 但引擎未实现，专家档题目逻辑推导会卡住）；三是本地数据无导出备份，卸载即全部丢失。

### 2.2 对局能力（`src/stores/game.store.ts`、`src/core/sudoku/`）

- 填数/笔记/擦除/单格与全盘候选；GIVEN 保护；错误即时标错与数字禁用联动。
- 撤销/重做上限 500 操作；候选清理与填写同操作可整体撤销；timeline 上限 1500 事件含截断基线。
- 检查（手动，可在暂停态）；提示先报错格 → 逻辑推导 → 兜底答案，同一步去重计数。
- 书签保存/恢复（可撤销）；暂停/恢复含后台时长结算；180ms 防抖存档，存储失败可重试。
- 结算幂等（lastSettlement 防重放）；奖牌金/银/铜规则；音效（tap/error/success）+ 震动 best-effort。
- 引擎技巧（`logical.ts`）：唯一候选、隐藏唯一、区块排除（Pointing/Claiming）、裸对、隐藏对、裸三数组、X-Wing，共 7 种，均带中文推导说明。

### 2.3 模式与题目供给

- **闯关**：3 系列各保留 25 道题库 + 26 关起确定性离线生成（7 阶段递进，种子固定保证跨设备一致，缓存 100 关并全量重校验）。
- **练习**：4 档技巧评级（入门/简单/进阶/专家），无限生成 + 近期 100 题去重 + 后台预热缓存。
- **每日**：本地日期种子，日历补玩、连续天数（含闰日/月边界处理）。
- **导入**：唯一解校验后开始 CUSTOM 局，支持存档/提示/回放。
- 只有 CAMPAIGN 首完成计积分，其他模式计历史/累计/每日记录。

### 2.4 设置（`src/types/settings.ts`，15 项全部有消费点）

高亮相关/相同数字、自动删候选、即时错误检查、后台自动暂停、完成数字禁用、智能草稿、自主推理模式、音效、震动、主题（深/浅）、棋盘配色、大字、输入方式（格先/数先）、引导标记。

### 2.5 数据与适配

- 统一结果存储 `sudoku:v3:results`：进度/历史 1000 条/累计/每日日期一次提交，兼容 v1 旧档迁移与结构校验。
- 折叠屏首批适配：动态窗口尺寸监听、≥640px 分栏棋盘、安全区 CSS 变量、宽屏弹窗浮窗、prefers-reduced-motion。
- 检查体系：typecheck、单元/业务/组件回归（含 300 道连续生成关卡抽检与窗口/交互专项）、75 题唯一解与评分校验、24 个 SFC 与 12 条路由检查。

## 4. 待补充功能与优先级

优先级依据：P1 影响可用性结论成立或数据安全；P2 是明确的体验/功能增强；P3 为长线方向。

### P1

1. **真机与正式构建验收**：项目至今未做原生/H5 正式构建与设备体验验证（`docs/PROJECT_OVERVIEW.md` 明确记录）。需要覆盖：手机/平板/折叠屏内外屏与铰链姿态、横竖屏与分屏、系统大字体、触摸尺寸、音效震动、后台/杀进程存档恢复。这是"功能完整度"结论能从源码成立升级为产品成立的前提。同时有 3 个历史任务停在待验收且证据已失效，需要用户逐个验收或发起恢复。
2. **本地数据导出/备份**：全部数据在 uni Storage 本地，无任何导出途径，卸载/换机即丢失全部进度、历史与成就。建议提供进度与存档的文本导出/导入（可复用现有 JSON envelope 与导入页校验思路）。

### P2

3. **解题引擎技巧扩展**：教程已向用户介绍 Swordfish 与 XY-Wing（`src/content/tutorial.ts:65-72`），但 `logical.ts` 未实现；专家档题目提示只能兜底给答案。补齐这两种技巧可同时提升提示教学性和专家档"纯逻辑可解"的比例。
4. **提示教学性增强**：当前提示为单步推导文案；可增加技巧相关格高亮（指明"为什么"），与教程条目互相跳转。
5. **成就体系扩充**：成就只有 5 个且内联在统计页；建议数据驱动定义（连续天数里程碑、无提示完成、奖牌累计、各模式局数等），并保留"初始题库通关"这类长期目标。
6. **完成庆祝与反馈丰富度**：目前动画仅有入场/格子过渡；结算无庆祝动效，音效仅 3 种。可补完成庆祝动画、结算音效、连击/进度反馈（需尊重 reduced-motion）。
7. **历史与复盘增强**：回放仅有步骤滑块；可增加按操作类型过滤、候选变化展示、记录分享（导出局面文本）。

### P3

8. **变体数独**：对角线、Jigsaw 等需要扩展 Core 约束模型与专门生成/校验管线，独立立项。
9. **每周挑战/主题商店等长线运营功能**：与离线定位不冲突但依赖内容生产管线，优先级最低。
10. **技术债**：`GameRecord.actions` 写死空数组（`game.store.ts:477`，动作记录实际依赖 timeline，历史记录归档裁切后动作级信息会丢失）；无障碍可补全行/列/宫读屏描述与不只依赖颜色的状态区分。
